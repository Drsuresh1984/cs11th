Memory Management

       Memory management refers to the management of the Primary Memory or Main Memory. Main memory is a large collection of words or bytes, each with its own unique address. It provides fast storage that the CPU can access directly. For a program to run, it must be loaded into the main memory. The Operating System performs the following tasks for memory management:

  1. Keeps track of the main memory, identifying which parts are in use and which are free.
  2. In a multiprogramming environment, it decides which process gets memory, when, and how much.
  3. Allocates memory to a process when it requests it.
  4. Deallocates memory when a process no longer needs it or has terminated.
