Assembly Language

       To make programming easier and reduce the difficulties of machine language, assembly language was developed. It is easier to read, write, and understand compared to machine language. Although it is still a low-level language, it uses mnemonic codes (short words) instead of binary numbers. For example, ADD means addition, DIV means division, and CMP means compare. Programs written in assembly language need a special translator called an assembler to convert them into machine language.

Advantages of Assembly Language:

  1. It is easier to undehrstand and use than machine language.
  2. Errors are easier to find and fix.
  3. Program instructions are simpler to modify.
  4. Programs written in assembly language use less memory and run faster.
  5. The programmer doesn't need to memorize many complex codes.

Disadvantages of Assembly Language:

  1. We  need to know the computer's processor architecture and instruction set to program in assembly language.
  2. Programs written in assembly language are not portable.
