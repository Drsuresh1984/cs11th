Device Management

       This function of the Operating System manages peripheral devices such as printers, mice, keyboards, and other hardware connected to the computer. The OS communicates with these devices through special software called device drivers. The Device Management function of the Operating System performs the following tasks:

  1. Keeps track of the status of each device, like disk drives, printers, and modems.
  2. Uses predefined rules to decide which process gets access to a device and for how long.
  3. Allocates and deallocates devices to user and system processes as needed.
