High Level Languages:

       High-level languages are similar to English. They use English words and mathematical symbols instead of mnemonic codes or binary numbers to write programs. Before a program written in a high-level language can run, each instruction is translated into machine language using a translator called a compiler or an interpreter.

Examples of High-Level Languages:

       Some common high-level languages are BASIC, COBOL, C, C++, FORTRAN, LISP, and PASCAL.

Advantages of High-Level Languages:

  1. They are easy to learn and understand.
  2. Programs written in high-level languages are portable i.e run on various hardware platforms.
  3. Programmers need not know hardware details.
  4. Finding and fixing errors (Debugging) is easier.
  5. Programs are easier to modify.

Disadvantages of High-Level Languages:

  1. High-level programs generally run slower.
  2. They typically require more memory.
  3. High-level programs cannot run directly; they require a compiler or interpreter to translate into machine code.
