Software:

      Software is a general term used to describe computer programs. A program is a set of instructions that helps the computer do one specific job. When many programs work together to complete a task, they form software. Software allows users to use the computer, control its parts (hardware), and do different activities on it.

Examples :

  1. MS Word – lets us type and edit documents.
  2. Google Chrome – helps us to  browse the internet.
  3. Windows or macOS – an operating system that runs the whole computer.
  4. Paint – a simple program used for drawing.
  5. Calculator – helps us solve math problems.
