1.3 Generations of Computer

Each step in the development of computers is called a generation. In every generation, there was some new change in hardware or software that made computers better and faster. Based on these changes, computers are grouped into following different generations.

(a) First Generation      (1942-1955)
(b) Second  Generation  (1955-1964)
(b) Third Generation     (1964-1975)
(d) Fourth Generation   (1975-1989)
(e) Fifth Generation       (1989 – Present)

(i) First Generation ( 1942-1955) :

S.No. Aspect First Generation Computers
1 Technology Used Vacuum Tubes
2 Memory A metal cylinder with magnetic coating
3 Input Method Punched Cards and Paper Tape
4 Output Method Printouts
5 Languages Used Machine Language and Assembly Language

image

Salient features of First generation computers:

  1. Huge in size
  2. Produced Lots of Heat
  3. High Power Usage
  4. Needed Air Conditioning
  5. Very Expensive
  6. Difficult to use 
  7. Not reliable

Examples:  ENIAC (Electronic Numerical Integrator and Computer), EDVAC (Electronic Discrete Variable Automatic Computer), UNIVAC I (Universal Automatic Computer) and IBM 701

1. Second Generation:  These computers were based on Transistors as

 Shown in fig. 1.10.  Transistors   were   superior   to   vacuum  tube. Magnetic core  was     used      for        memory.      Magnetic          tapes         and          Disks       were  used   for   secondary   storage.  Assembly   language with mnemonics such as ADD, MULT rather than numbers was used. Early High Level Languages such as COBOL And FORTRAN also came into existence in this period.Batch operating Systems were  Suitable for second generation computers.

Characteristics of Second Generation Computers: These Computers were:

  1. Smaller in size and produced less heat
  2. Faster
  3. More reliable 
  4. Easier to program than previous generation systems
  5. Costly 

Examples:  PDP-8,  IBM 1401 and Honeywell 400

2. Third Generation:  Integrated Circuit( IC ) as Shown in fig. 1.11.

was   the   trait   of   the   third    generation    computers.   An    Integrated Circuit  consists of a single chip( usually silicon) with many components such as transistors  and resistors    fabricated   on  it.  Small   Scale   Integration  (SSI)   and   Medium  Scale  Integration (MSI)   was   used.    Larger   Magnetic   core   was  used   for    memory.    Larger   capacity   disks  and  magnetic  tapes   were  used  as secondary storage.    User   interacts   with   these   systems   through   Keyboards   and   monitors. Timesharing operating Systems were suitable for these computers.This allowed the device to run many applications at one time. 

Characteristics of Second Generation Computers: These Computers were:

  1. Smaller in size and produced much less heat
  2. More reliable, efficient and faster 
  3. Extensive use of high level languages became possible.
  4. Commercial production became easier and cheaper

1) Used for Scientific, commercial and interactive online applications

Examples:  PDP-11,  CDC-6600,  IBM 360/370.

3. Fourth Generation:  Fourth Generation machines were  based  on  microprocessor

. A microprocessor is a single chip on which all the components of a computer such as the central processing unit, memory and input and output controls are embedded. Microprocessors  (circuits containing millions of transistors) led to LSI (Large Scale Integration), VLSI( Very Large Scale Integration) technology. This generation also saw the development of GUIs( Graphical User Interfaces), mouse and handheld devices. Larger capacity hard disks as in-built secondary storage were used. Magnetic tapes and floppy disks were used as  as portable storage media.

Characteristics of Second Generation Computers: These Computers were:

  1. Small, affordable, and easy to use 
  2. Totally general purpose machines
  3. Easier to produce commercially.
  4. Produced at a very low cost.
  5. Portable and quite reliable.

Examples:  APPLE-II,  CRAY-1,  IBM PC, VAX 9000.

(v) Fifth Generation:  The starting point for the fifth generation of computers has been set in the early 1990s. In the fifth generation,VLSI technology became ULSI (Ultra Large Scale Integration)  technology. Three characteristics can be identified with the fifth generation computers are Mega Chips, Parallel Processing and Artificial Intelligence.These systems has Larger capacity main memory.Key software technologies used in fifth generation include Parallel programming, JAVA, WWW, Multimedia, Internet and Distributed Operating Systems.

Characteristics of Second Generation Computers: These Computers were:

  1. Powerful, cheaper, reliable, and easier to use.
  2. Incorporates\d Self-learning abilities. 
  3. Totally general purpose machines
  4. Easier to produce commercially.
  5. less expensive than the recent generation.
  6. Portable.

Examples:  Pentium PCs,  IBM notebooks,  PARAM 10000.
