File Management

       File Management is the process of handling files within a computer  system. A file is a collection of related data stored in the computer's memory. File Management involves creating, modifying, and deleting files. The Operating System performs the following tasks as part of File Management:

  1. Transfers files between the main memory and secondary storage.
  2.  Manages files and folders (directories).
  3.  Allocates space on secondary storage for files.
  4.  Controls file sharing and ensures file protection.
  5.  Recovers files in case of errors or data loss.
