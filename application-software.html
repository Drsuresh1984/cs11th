Application Software

      Application software is a type of software that is made to do specific tasks. Each application software is designed to solve a particular problem. For example, a spreadsheet software is used to work with numbers and do calculations, it cannot be used for anything else. In the same way, a hospital management software helps in managing hospital work only, not any other kind of work.

Here are some commonly used types of application software:

  1. Word Processing Software : Used for typing and editing text (e.g., MS Word).
  2. Spreadsheet Software : Used for working with numbers and calculations (e.g., MS Excel).
  3. Presentation Software : Used to create slideshows and presentations (e.g., MS PowerPoint).
