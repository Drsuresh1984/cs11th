Interpreter :

       An interpreter is a software tool that converts a high-level language program into machine-understandable code. Unlike a compiler, it works line by line — it reads a line of code, translates it, executes it, and then moves to the next line. If there is an error in any line, the interpreter stops execution immediately and shows the error message. It will not continue until the error is fixed. Languages like BASIC and Python commonly use interpreters.
