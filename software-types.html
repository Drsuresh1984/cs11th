Types of Software:

      Software can be divided into different types according to the work it performs. The three important types of software are System Software, Application Software, and Utility Software.

Types :

  1. System Software : Controls and manages computer hardware and provides a platform for other software.
  2. Application Software : Helps users perform specific tasks such as writing, drawing, browsing, or calculations.
  3. Utility Software : Helps maintain, protect, and improve the performance of a computer system.
