Machine Language

       It is a low level language. It is a sequence of instructions written in the form of binary numbers consisting of 1's and 0's to which the computer responds directly. Thus , Machine language is a collection of binary digits or bits that the computer reads and interprets.It is the only language understood by a computer directly.

Advantages of Machine Language:

  1. It is directly understood by the computer.
  2. No translator programs, like compilers or interpreters, are needed.
  3. It allows the computer to run programs very quickly and efficiently.

Disadvantages of Machine Language:

  1. Programming in machine language is very difficult.
  2. The programmer must remember many complex codes to write a program.
  3. Finding and fixing errors (debugging) is hard.
  4. Writing programs in machine language takes a lot of time and is expensive.
