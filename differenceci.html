Compiler vs Interpreter

S.NO. Compiler Interpreter
1 Takes the entire program as input. Take one instruction at a time.
2 Translate the whole code at once. Translates and executes line by line.
3 Generates intermediate object code. Does not generate object code.
4 Uses more memory. Uses less memory.
5 Shows errors after compiling the entire program. Shows errors immediately when they occur.
6 Not needed during execution. Must be present during execution.
7 Debugging can be harder due to delayed error reporting. Easier debugging as errors are shown instantly.
8. Examples: C, C++, FORTRAN, Pascal, COBOL Examples : Python, BASIC, Ruby, JavaScript
