Compiler :

       A compiler is a software tool that translates a program written in a high-level language into machine language. The original high-level program is called source code, and the translated, executable version is called object code. This object code can run independently without needing the compiler at runtime. The compiler converts the entire source code into object code in one go. It also checks the source code for syntax errors and reports them if found. Each programming language has its own specific compiler. Examples of languages that use compilers include C++, FORTRAN, COBOL, and Pascal.
