Utility Software:

      Just like hardware, software in a computer also needs care and maintenance. For this, we use a special type of software called utility software. It is a small program that does a specific job to help keep the computer running well. Utility software is actually a type of application software that supports the system software in doing its work better.

Here are some common examples of utility software:

  1. Antivirus software :Protects the computer from viruses.
  2. Disk management tools : Help manage and organize the hard drive.
  3. File management tools : Help store, move, or delete files easily.
  4. Compression tools : Reduce the size of files to save space.
  5. Backup tools : Make copies of important data to keep it safe.
